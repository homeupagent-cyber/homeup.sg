# New Launch Review: Data Intake Checklist

Use one checklist per launch. Collect what you can, upload it into a new chat in the Technology & Coding project, and say: "Build the launch review data file for [project name]." Claude returns the data file and review copy; Claude Code adds the page.

Tick each item and note the date you got it. Anything missing stays "TBC" on the page.

---

## A. From the developer (via the appointed agency's co-broke kit)

**Before you collect anything:** check the co-broke terms on what you may publish. Use developer material for analysis only. Do not republish renders, brochure pages, floor plan images or the raw price list unless you have written permission.

### Phase 2: when the e-brochure is released

| # | Item | Why it matters | Got it? |
|---|---|---|---|
| A1 | **Site plan with block numbers, stack numbers, north arrow and scale bar** | Places towers and stacks in the 3D model. Without a scale bar and north arrow, positions are guesswork | |
| A2 | **Unit distribution chart** (which stack is which unit type, on which floors) | Colour-tags stacks by unit type | |
| A3 | **Floor plans for every unit type, with sizes (sq ft and sqm)** | Size comparisons, layout efficiency notes | |
| A4 | **Unit mix table** (type, size range, number of units) | Supply per type, scarcity of large units | |
| A5 | **Storeys per block and floor-to-floor height** (from elevation or section drawings) | Correct tower heights, so the sun study is accurate | |
| A6 | Facilities list and their positions on the site plan | Which stacks face pool, carpark, substation, refuse point | |
| A7 | Expected TOP and legal completion dates | Timeline, MOP and privatisation dates for ECs | |
| A8 | Developer, architect, main contractor | Track record notes | |
| A9 | Specs: kitchen and bathroom brands, aircon type, smart home | Like-for-like comparison | |
| A10 | Carpark lots and ratio, estimated maintenance fee | Running cost comparison | |

## B. Public data (Claude or Claude Code pulls this, you do not need to collect it)

- GLS tender result: site area, plot ratio, land price, psf ppr, tender date (HDB / URA)
- Plot boundary (URA Master Plan, SLA)
- Surrounding buildings and HDB block heights (OpenStreetMap, data.gov.sg)
- Distances to MRT/LRT, expressways, schools, malls (OneMap, MOE list)
- Upcoming land sales and launches nearby, so future supply is visible (URA GLS programme)
- **Resale and rental transactions for comparison projects** (URA Data Service, using HomeUP's URA key)

---

## C. Resale comparison set (you choose, Claude pulls the numbers)

Pick 3 to 5 comparison projects. Claude can propose a list for you to approve.

| # | Item | Notes | Got it? |
|---|---|---|---|
| C1 | **Resale ECs nearby** (within about 1.5 km) | The like-for-like alternative for EC buyers | |
| C2 | **Resale private condos nearby** of similar age or newer | What the same budget buys today | |
| C3 | **Other new launches competing at the same time** | e.g. the second EC on the same road | |
| C4 | Staying in HDB (the buyer's own flat) | The "do nothing" option | |
| C5 | For each comparison: name, TOP year, tenure, lease start, EC privatisation status | Lease and age adjustments | |

Claude then pulls 12 to 24 months of transactions (psf, size, floor, date) and rental contracts for each, and works out price gaps and rental yields.

**Optional from your team:** current asking prices and listing agent feedback on comparison projects, and 99.co Home Reports for specific units. These sharpen the comparison.
